申報詳情

編輯業務欄位

Urgent Order：可修改 SKU、QTY（1 至 1000）及 Urgent Reason，Site Code 不可修改。選擇「9. 其他」時必須填寫 Other Reason。

版本歷史

SAP Excel 匯出（一般 NDRF）

只會匯出一般 NDRF。匯出後該批會被鎖定，申請人不能再修改。預覽下載不會鎖定。

Urgent Order Excel 匯出

只會匯出 Urgent Order。匯出後鎖定，不能修改。預覽不會鎖定。

突發性銷售申報 Excel 匯出

欄位：Application Date | Requested by | Shop Code | SKU。匯出後鎖定。

行貨退貨報數 Excel 匯出

8 欄：申請編號、申請日期、Requested by、SKU、QTY、Reason、確認人姓名、電話。

正式匯出批次及重新下載

正式匯出檔案保存三個月。若瀏覽器下載中斷，可從這裡重新下載。
