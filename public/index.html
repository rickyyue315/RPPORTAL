使用說明

本頁用於 一般申報（ND／RF 申請）。以下說明協助你正確填寫各欄位，不影響原有功能。

一、填寫步驟

  1. 輸入 Site Code（例如 HA02），輸入後系統會自動驗證門店；
  2. 輸入 SKU；
  3. 選擇 RP Type（ND 或 RF）；
  4. 按 RP Type 填寫相應欄位（見下節）；
  5. 按「預覽」核對資料，確認無誤後按「確認提交」。

二、欄位填寫規則

  • 只有 Site Code、SKU 及 RP Type 為必填；
  • RP Type 為 RF：必須填寫 Safety stock，且為大於 0 的數字；ND Code 不需填寫；
  • RP Type 為 ND：必須填寫 ND Code；Safety stock 不需填寫；
  • 部分指定店舖轉 RF 時，必須填寫 Remark，否則無法提交。

三、本身已是 RF、只想修改 Safety stock

即使只是調整 Safety stock（不作其他更改），仍需在 RP Type 選擇 RF，並於 Safety stock 填寫新的數值後提交；如改為其他 RP Type，請按該 Type 的規則填寫。

四、提交之後

  • 提交成功後請記下申請編號；
  • 可到「查詢／修改」頁面，以「申請編號 + Site Code」查看，並在匯出前修改（每次修改會新增一個版本紀錄）；
  • 匯出後申報會被鎖定，不能再修改。

五、Excel 批量上載

使用固定模板（工作表 RP Team），一行代表一筆申請。整份檔案會先完整驗證，任何錯誤都不會寫入資料；規則與單筆申報相同（RF 必須填 Safety stock 等）。
