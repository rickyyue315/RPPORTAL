RP Team 每週會發出你店舖的指定 90 日零銷售 SKU。直接進入後輸入 Site Code（例如 HA02），即可逐條選擇回覆原因。每個 SKU 可修改一次。輸入一次 Site Code 後，其他頁面會自動認到係你嘅店。
