90日零銷售 SKU 回覆（店舖首頁）

RP Team 每週會發出店舖的指定90日零銷售SKU，直接進入後輸入所屬店舖嘅 Site Code（例如 HA02），即可逐條選擇回覆原因。每個 SKU 可修改一次。輸入一次Site Code後，其他頁面會自動認到係你嘅店。轉換其他店舖需要登出。其他項目請使用公司的Portal。

直接進入回覆頁（店舖首頁） 使用說明
回覆規則：選擇「6.其他」必須填寫補充說明；已回覆的SKU只可再修改一次，之後會鎖定。

一般NDRF申報（ND／RF／改 Safety）暫停收單

與零銷售回覆同一模式：輸入店舖 Site Code 後自動認店，唔使密碼。目前暫停收單，仍可進入查看「我的申請」舊紀錄及審批狀態。

進入一般NDRF申報 使用說明

Urgent Order暫停收單

與零銷售回覆同一模式：輸入一次自己店舖嘅 Site Code 後自動認店。目前暫停收單，仍可進入查看頁面及說明。

進入 Urgent Order 使用說明

與零銷售回覆同一模式：輸入一次自己店舖嘅 Site Code 後自動認店。目前暫停收單，仍可進入查看頁面及說明。

進入突發性銷售申報 使用說明

行貨退貨報數暫停收單

與零銷售回覆同一模式：輸入一次自己店舖嘅 Site Code 後自動認店。目前暫停收單，仍可進入查看頁面、時間表及說明。

進入行貨退貨報數 使用說明

查詢／修改

適用於 URGENT-、SALES- 及 RETURN- 開頭的申請。如已輸入 Site Code，會自動帶入，唔使重複輸入。

進入查詢／修改 使用說明

需要幫助？

第一次使用？店舖請先到「90日零銷售回覆（店舖首頁）」輸入 Site Code；其他頁面可到獨立的圖文使用說明，按照步驟查看。一般NDRF申報、Urgent、突發性銷售及行貨退貨暫停收單中，仍可進入查看。
