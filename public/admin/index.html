申報詳情

編輯業務欄位

Urgent Order：可修改 SKU、QTY（1 至 1000）及 Urgent Reason，Site Code 不可修改。選擇「9. 其他」時必須填寫 Other Reason。

版本歷史

SAP Excel 匯出（一般 NDRF）

只會匯出一般 NDRF 申報，Urgent Order 使用下方的獨立匯出。匯出後該批申報會被鎖定，申請人不能再修改。匯出失敗不會鎖定。預覽下載不會鎖定申報。

Urgent Order Excel 匯出

只會匯出 Urgent Order（欄位：Application No. | Site Code | SKU | QTY | Urgent Reason | Other Reason）。匯出後該批 Urgent Order 會被鎖定，不能修改。匯出失敗不會鎖定。預覽下載不會鎖定申報。

突發性銷售申報 Excel 匯出

只會匯出突發性銷售申報，欄位為 Application Date | Requested by | Shop Code | SKU。匯出後該批申報會被鎖定，不能修改；匯出失敗不會鎖定。預覽下載不會鎖定申報。

行貨退貨報數 Excel 匯出

輸出 8 欄：申請編號、申請日期、Requested by（Site Code）、SKU、QTY、Reason、確認人姓名、確認人電話。預覽不鎖定；正式匯出後店舖不能再修改。

正式匯出批次及重新下載

正式匯出檔案保存三個月。若瀏覽器下載中斷，可從這裡重新下載；三個月前的舊批次會嘗試按已鎖定申報資料重新產生。
