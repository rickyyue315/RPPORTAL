1. 一般申報（ND／RF）

適合提交一般 NDRF 申報。先填寫基本資料，再按 RP Type 填寫相應欄位。

1輸入並確認店舖

在 Site Code 輸入店舖編號，例如 HA02。稍等片刻，系統會顯示店舖名稱；請先確認顯示的店舖正確。

2填寫 SKU 及 RP Type

SKU 及 RP Type 必須填寫。選擇 ND 或 RF 後，按下列規則填寫：

選擇 ND

必須填寫 ND Code。可選項目只有：

ND20ND21ND22ND23ND29
選擇 RF

必須填寫大於 0 的 Safety stock；指定店舖另須填寫 Remark。

3預覽、確認及記下申請編號

按「預覽」後，逐項核對資料。確認正確後按「確認提交」。成功後會顯示申請編號，請立即記下，日後查詢或修改時需要使用。

小提示：如果只想調整 Safety stock，也要將 RP Type 選擇為 RF，並填寫新的 Safety stock。

2. Excel 批量上載

如果要一次提交多筆申報，可使用 Excel 模板。請不要更改工作表名稱及第一行欄名。

1下載模板並填寫

按「下載模板 (.xlsx)」，在 RP Team 工作表逐行填寫資料。每一行代表一筆申報；保留第一行欄名，不要自行改名或刪除欄位。.xlsx 是 Excel 活頁簿格式，支援 Excel 2007 或更新版本，包括 Excel 2019、Excel 2021、Excel 2024 及 Microsoft 365；舊式 .xls 檔案請先另存為 .xlsx。

2上載並核對結果

將檔案拖到上載框，或按一下選擇檔案，再按「上載並匯入」。系統會先完整檢查整份檔案；如有任何錯誤，整份檔案都不會寫入。成功後請記下每筆申請編號。

Excel 批量上載的欄位規則與一般單筆申報相同：ND 要填 ND Code；RF 要填大於 0 的 Safety stock，指定店舖轉 RF 要填 Remark。

3. Urgent Order

Urgent Order 用於緊急補貨，與一般 NDRF 申報分開處理。

1填寫緊急補貨資料

按「Urgent Order」，填寫 Site Code、SKU、QTY 及 Urgent Reason。QTY 必須為 1 至 1000 的整數；選擇「9. 其他」時，必須填寫 Other Reason。

2預覽或使用 Excel 批量上載

單筆申報按「預覽」後確認提交；多筆申報可下載 Urgent Order 模板，上載前保持工作表及欄名不變。每日香港時間 14:30 後暫停收單，請於翌日 14:30 前提交。

Urgent Order 有提交時間限制，必須 14:30 前提交。

4. 突發性銷售申報

突發性銷售申報只需填寫 Site Code 及 SKU，沒有提交時間限制。

1填寫 Site Code 及 SKU

按「突發性銷售申報」，輸入 Site Code 及 SKU，兩項均為必填。輸入 Site Code 後會自動顯示門店名稱，請先確認店舖正確。

2預覽提交或使用 Excel 批量上載

單筆申報按「預覽」後確認提交；多筆申報可下載獨立模板，在 突發性銷售申報 工作表填寫 Site Code、SKU 兩欄。整份檔案會先完整驗證，任何錯誤都不會寫入；成功後可下載按店舖分頁的匯入記錄。

突發性銷售申報沒有提交時間限制，任何時間都可提交。

5. 行貨退貨報數

行貨退貨報數用於提交需要 Buyer 審批的行貨退貨申請。單筆申請及 Excel 批量上載使用相同欄位及驗證規則。

1確認申請日期及庫存

按「行貨退貨報數」進入申請頁。先參考頁面上的 2026 年店舖申請退行貨時間表，確認目前仍在開放日期內，再到庫存分析報表檢查有足夠機數。

報數後請即時收起退貨，不可繼續售賣。2026 年 8 月至 12 月只會在指定店舖申請窗口收單；窗口結束後不可新增申請。

2填寫退貨資料

Site Code 必須是有效店舖；SKU 只接受一個 7 位或 12 位數字；QTY 必須是 1 至 9999 的整數；確認人姓名及電話必須填寫。

REASON 必須從指定選項選擇：

1. BUYER MEMO指定退貨 2. BUYER 電郵確認可退-期貨 3. BUYER 電郵確認可退-壞貨 4. 供應商確認可退-期貨 5. 供應商確認可退-壞貨 6. 供應商確認可退-下架貨

3預覽、提交及記下申請編號

按「預覽」逐項核對資料，確認無誤後按「確認提交」。成功後會產生 RETURN- 開頭的申請編號，請記下申請編號，日後查詢或修改時需要使用。

退行貨申請需要交由 Buyer 審批，約七個工作天後出退行貨號碼。系統本身不會顯示 Buyer 是否接受，也不會在此頁產生退貨 NO.。

4使用 Excel 批量上載

在「行貨退貨報數」頁下載模板。工作表名稱及第一行欄名不可更改；每一行代表一個 SKU 申請，欄位依次為 Site Code、SKU、QTY、REASON、確認人姓名、確認人電話。

完成後將 `.xlsx` 檔案拖到上載框或按一下選擇檔案，再按「上載並匯入」。系統會先完整驗證整份檔案，任何一行有錯誤時整份檔案都不會寫入。成功後可下載按店舖分頁的匯入記錄。

重要注意事項
經常更改已建立退貨單數量或加減 SKU，下期退行貨申請會被暫停一次。
如機數不足、沒有註明申請退貨原因、重複申請或 Buyer 不接受退貨申請，將不會出退貨 NO.。
已有退貨 NO. 之 SKU 已經 block 數，不用盤點。
同一個退行貨申請窗口內，同一 Site Code 及 SKU 只可申請一次；如要更正，請使用「查詢／修改」修改原申請。

6. 查詢／修改

提交成功後，可使用申請編號及 Site Code 找回申報資料。

1輸入兩項資料查詢

按「查詢／修改」，輸入提交後的 申請編號 及當時使用的 Site Code，再按「查詢」。兩項資料必須同時正確。

2匯出前可以修改

資料顯示後，可在匯出前修改並按「儲存修改」。每次修改會新增版本紀錄；管理員匯出後，申報會被鎖定，不能再修改。突發性銷售申報只可修改 SKU，且沒有時間限制。行貨退貨報數只可在原本所屬的店舖申請退行貨窗口內修改，窗口結束後只可查詢。

如需重新開始，按頁面上方的「一般申報」、「Urgent Order」、「突發性銷售申報」或「行貨退貨報數」即可返回。
